# Aveline Dental Studio — High-Performance Digital Flagship (Sample 2)

A 1:1 bespoke digital flagship crafted for **Aveline Dental Studio** (modern dentistry with a gentle touch).

## Highlights
- **Architecture:** Zero-slop bespoke editorial layout with tactile dental & clinical aesthetics.
- **Motion Engine:** Native CSS `linear(...)` harmonic oscillator easing curves, custom marquee ticker, and zero-dependency view transitions bridge.
- **Performance:** 100% self-contained offline asset bundle with pre-optimized responsive WebP media, custom WOFF2 typography, and zero third-party platform bloat.
- **Analytics:** Integrated Vercel Web Analytics.

## Deployment
Deployed via Vercel with clean URLs, immutable asset caching headers, and real-time analytics.
